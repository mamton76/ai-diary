# AI Diary — инструкции для агентов

Этот файл — короткая точка входа для ChatGPT/Codex и других агентов, работающих с репозиторием.

## Текущая фаза

Пока не утверждён новый architecture baseline, приоритет имеет работа с:

```text
docs/baseline/
```

Не считать старую Android/Firebase архитектуру обязательной только потому, что она уже реализована или описана в старых документах.

## Язык

Проектные документы и обсуждения по умолчанию вести на русском. Идентификаторы, API names, code symbols и названия технологий можно оставлять на английском.

## Project skills

Канонические skills:

```text
skills/
```

Перед работой с открытыми вопросами, спорными требованиями и design decisions прочитать:

```text
skills/discussion-threads/SKILL.md
```

## Правила решений

- Не выдавать открытый вопрос за принятое решение.
- Не приписывать пользователю позицию, которой он не высказывал.
- Долгие спорные вопросы вести через discussion threads.
- Принятое решение переносить из thread в соответствующий source-документ.
- Историю пересмотренных решений не стирать.
- Если ChatGPT/Codex и Claude расходятся, сохранять обе аргументированные позиции и отдавать реальный выбор пользователю.
