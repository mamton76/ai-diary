# Decision 0001 — документация входит в завершение задачи

**Статус:** согласовано в обсуждении с Product Owner, 2026-11-15.

## Решение

Каждая задача обязана содержать Documentation Impact. Исполнитель обновляет актуальные документы при необходимости; Reviewer проверяет их соответствие изменённой реализации. При отсутствии влияния агент явно обосновывает «none». Задача не завершена, пока этот gate не пройден.

## Обоснование

Техническая документация не должна отставать от реального состояния AI Diary. При этом запланированное, принятое и реализованное нельзя смешивать.

## Следствия

- Документ обновляется в той же ветке/PR, что и код.
- Изменение требований требует отдельного согласования, а не неявной правки.
- В результате задачи приводятся ссылки на изменённые source docs или мотивированный отказ от правок.
