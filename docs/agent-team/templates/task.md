## План и исполнители

Каждый шаг — Markdown checkbox с ответственным, проверяющим, временем постановки и временем закрытия. Формат timestamp: ISO 8601 с часовым поясом (`YYYY-MM-DDTHH:MM:SS+HH:MM` или `Z`).

- [ ] **S1 — Название шага**
  - **Исполнитель:** Claude / Codex / Orchestrator
  - **Проверяет:** независимый агент / CI / пользователь
  - **Поставлен:** `YYYY-MM-DDTHH:MM:SS+HH:MM`
  - **Закрыт:** — (проставляется только при выполнении и отметке [x])
  - **Зависит от:** —
  - **Результат / evidence:** ссылка на коммит, PR, тест или документ

- [ ] **S2 — Следующий шаг**
  - **Исполнитель:** ...
  - **Проверяет:** ...
  - **Поставлен:** `YYYY-MM-DDTHH:MM:SS+HH:MM`
  - **Закрыт:** —
  - **Зависит от:** S1
  - **Результат / evidence:** —

**Правила:** время постановки фиксируется при добавлении пункта, время закрытия — в момент фактического завершения; checkbox и время закрытия изменяются одновременно. Для старых шагов без достоверных timestamps указывать «не зафиксировано», не придумывать даты. Если шаг переоткрыт, сохранить историю прежнего закрытия в discussion/ и вернуть checkbox в [ ] с текущим статусом. Не отмечать [x] лишь потому, что исполнитель назначен.
