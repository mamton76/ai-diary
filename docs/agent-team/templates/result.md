# Результат TASK-NNNN

**Status:** in-progress | ready-for-human | completed | blocked
**Date:** YYYY-MM-DD
**External links:** Issue / PR / CI (необязательно)
**Presentation:** путь к переносимой презентации или not-needed с причиной

## Что сделано

Фактически выполненные изменения, ссылки на файлы/коммиты.

## Проверки и доказательства

| Gate | Результат | Ссылка / лог |
|---|---|---|
| Acceptance criteria | pending | — |
| Tests / build / CI | pending | — |
| Independent review | pending | — |
| Documentation Impact | pending | — |
| Presentation / human review | pending / not-needed (reason) | presentation/index.html или другой путь |
| Open blocking issues | pending | — |

Не писать «тесты пройдены», если они не запускались.

## Актуализация документации

Изменённые source docs, статусный план, ссылки на canonical decisions. Или обоснованное Documentation Impact: none.

## Существенные обсуждения

Итог разногласий и решения со ссылками на discussion/threads/ и внешние отзывы.

## Презентация результата

Ссылка на локальный файл в `presentation/`, какой сценарий в нём демонстрируется, что проверено независимым reviewer. Для простой задачи: `not-needed` и обоснование.

## Что нужно от пользователя

Конкретное решение, approval, либо «ничего».

## Итоговый статус

Не выставлять completed до принятия задачи и выполнения Definition of Done.
