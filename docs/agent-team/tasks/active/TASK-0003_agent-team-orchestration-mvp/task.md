## Цель и границы

Получить первый безопасный и проверяемый механизм взаимодействия агентов, начиная с устранения конфликтов идентификаторов задач: один центральный регистратор записывает новые задачи в `master` **после разрешённого dispatch**, Claude и Codex получают уже выданные ID и не создают `TASK-NNNN` самостоятельно.

Этапы следующего уровня — назначение и передача шагов между облачными агентами, CI/ревью, восстановление сбоев и сводки. Они не должны выдаваться за действующие функции, пока не подключены и не протестированы реальные адаптеры.

**Не входит:** auto-merge, live diary/Abacus/Google, обход защиты master, автоматическая публикация отчётов с приватными данными, скрытые платные API-вызовы.

## Безопасность

Никаких реальных diary data, Abacus, Drive/Calendar; входы регистрации — только безопасная постановка без секретов. `master` может менять только доверенный registrar при разрешённом dispatch; регистрация ≠ исполнение. Слияние feature PR вручную.
