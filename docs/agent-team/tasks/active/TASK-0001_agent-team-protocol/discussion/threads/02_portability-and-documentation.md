## Вопрос

Как хранить историю вне зависимости от GitHub и поддерживать документацию проекта актуальной?

## Варианты

1. Хранить задачи только в GitHub.
2. Вести полные задачи и важные обсуждения в репозитории; GitHub использовать как внешний интерфейс.
