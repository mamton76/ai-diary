## Вопрос

Как организовать совместную разработку AI Diary силами Claude Code Cloud и Codex Cloud и как показывать результат пользователю?

## Варианты

1. Локальные CLI-агенты и локальный оркестратор.
2. Собственный постоянно работающий сервер.
3. Штатные облачные среды Claude/Codex с GitHub как интерфейсом и тонким оркестратором.

## Контекст и evidence

Обсуждение 8–15 ноября 2026: пользователь предпочитает облачную работу и готов получать суммаризированное общение агентов через GitHub. Окончательные API/интеграции ещё не реализованы и должны быть проверены отдельной задачей.

## Обсуждение

пользователь — выбрана облачная разработка, GitHub достаточен как интерфейс, если доступны понятные сводки обсуждений.

Предлагаемая реализация — роли Planner, Developer, Reviewer, QA и Orchestrator логические; независимый reviewer получает diff и исходные критерии. Отдельный UI не обязателен на старте. Контроль итогового merge остаётся у пользователя.

**Решение:** [принято] (2026-11-15) Документировать cloud-first команду Claude + Codex, GitHub как интерфейс, независимое ревью, переносимые итоги и контроль решений пользователем. Не объявлять облачную автоматизацию действующей до реализации.
