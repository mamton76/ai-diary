# Decision 0001 — переносимая история работы агентов

**Статус:** согласовано в обсуждении с Product Owner, 2026-11-15.

## Решение

Канонические задачи, существенные аргументы и результаты — Markdown-файлы в репозитории. GitHub используется как adapter для Issue/PR/комментариев, не как единственное хранилище. Текущие правила живут в README соответствующего раздела; аргументация — здесь и в task discussion.

## Обоснование

Пользователь хочет сохранить работоспособность документации при смене GitHub и получать краткие сводки вместо обязательного чтения переписки агентов.

## Следствия

- У задач независимые от GitHub IDs.
- Внешние ссылки полезны, но не заменяют содержимого задачи.
- Разногласия не стираются из истории и не выдаются за принятые решения.
