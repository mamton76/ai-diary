## Вопрос

Удобная копия `entries/…/entry.md` (materialized view) сейчас содержит только текст записи; заголовок, дата события и теги лежат в JSON. Добавлять ли в неё шапку, чтобы файл читался без приложения?

## Варианты

1. Шапка (YAML front matter): заголовок, дата и пояс события, теги; затем текст.
2. Только текст, как в черновике.

## Контекст

- `entry.md` — materialized view, не источник истины (07 §2.1); `revisions/<id>/text.md` остаётся чистым текстом Revision.
- DATA-010: экспорт E0 — это сами canonical-файлы плюс документ «как читать свои данные без приложения».
