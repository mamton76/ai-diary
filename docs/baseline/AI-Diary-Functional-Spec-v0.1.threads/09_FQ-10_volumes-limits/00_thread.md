## Вопрос

Source: «Объёмы данных, latency/availability targets, upload limits — без них нельзя объективно оценить производительность».

## Варианты

1. Задать целевые цифры и лимиты сейчас.
2. Не ограничивать, собрать реальные цифры и решить по ним.

## Контекст

- Продукт — личный инструмент одного пользователя ([PQ-018](../../04-open-questions.threads/56_PQ-018_portfolio-goal/00_thread.md)).
- Backend на Cloud Run (API-004). У Cloud Run размер HTTP/1-запроса ограничен 32 MiB, при HTTP/2 end-to-end ограничения нет ([Cloud Run quotas](https://cloud.google.com/run/quotas)).
- OPS-006 / OPS-007: структурированные логи и продуктовая телеметрия без содержимого записей.

## Обсуждение

пользователь — FQ-10 — объёмы и лимиты. давай пока не будем ограничивать - пожем - измерим - решим?

Claude — Согласен, с двумя оговорками. (1) Ограничение Cloud Run в 32 MiB на HTTP/1-запрос от нашего решения не зависит: большое видео через backend не пройдёт, поэтому дизайн загрузки должен его обходить — загрузка клиентом прямо в Drive (resumable upload) с регистрацией результата в backend или HTTP/2 end-to-end. (2) «Измерим» работает, только если с E0 собирать: число записей и вложений, размеры файлов (медиана и максимум), время Save до «Сохранено», задержки и ошибки Drive API включая квоты, время перестройки индекса — без содержимого записей.

Claude — Явного подтверждения оговорок не было: следующим сообщением пользователь перешла к вопросам дайджеста. Решение ниже фиксирует её выбор (вариант 2); две оговорки записаны как технические условия и могут быть пересмотрены по её слову.

**Решение:** [отложено] (2026-11-15) Продуктовые лимиты объёмов, задержек и размера загрузки сейчас не вводятся; цифры собираются на реальном использовании, и решение принимается по ним. Технические условия, не зависящие от выбора: с E0 собираются метрики (число записей и вложений, размеры файлов, время Save, задержки и ошибки Drive API, время перестройки индекса) без содержимого записей; дизайн загрузки обходит ограничение Cloud Run в 32 MiB на HTTP/1-запрос.
