## Вопрос

Предложенная пользователем настройка отключения показа/учёта архивных записей относится только к Calendar либо также к другим показателям Home?

## Варианты

1. Только Calendar и список по выбранному дню/диапазону; прочие scopes Home сохраняются.
2. Также к статистике Home, с одинаковым переключением показателей и списков по их клику. Потребуется явно уточнить, распространяется ли это на рабочие очереди Drafts/Needs attention и отдельно Active-only widgets.

## Контекст

- [SQ-06](../06_SQ-06_home-calendar-scope/00_thread.md) задаёт Calendar default ACTIVE + ARCHIVED, без TRASH. В нём сохранена полная реплика пользователя с идеей настройки.
- Calendar не показывает counts/state badges в ячейках; «учёт» означает участие в индикаторе наличия записей и связанном списке, не добавление нового числа.
- Home counters Total/Drafts/Needs attention/периодная статистика имеют ранее принятый ACTIVE + ARCHIVED scope без TRASH; EntryList и TagCloud — ACTIVE. User setting не должна молча переопределять эти решения.
- При исключении архива из выбранного виджета scope показателя/индикатора и результата перехода должны оставаться одинаковыми.
- Рабочий label «Учитывать архивные», default включён; название, layout, persistence path и окончательная область пока не утверждены.
- Настройка отображения/учёта не удаляет записи и не меняет их lifecycle, историю, content или физический storage.

## Обсуждение

Codex — (2026-10-18) Идея настройки принята к уточнению. Для Calendar выключение означало бы исключение ARCHIVED одновременно из выделения дней и списка по клику. Нужно определить область: только Calendar или также статистика Home. Не назначаю глобальную policy на основании реплики с «возможно».

пользователь — (2026-10-18) «все показатели галвноей конечно»

Codex — (2026-10-18) Принята одна настройка всей главной: календарь, вся Statistics включая Drafts/Needs attention, TagCloud и EntryList. Она меняет и показ, и подсчёт, и lifecycle-условия переходов. Это явное позднее уточнение заменяет Active-only scope Home TagCloud/EntryList; прежние решения сохранены в истории. По умолчанию включена; выбор сохраняется между посещениями. Labels/layout и физический persistence path остаются деталями реализации. Счётчики каталога Tags и Asset Library вне Home этим решением не меняются. Решение перенесено в Functional/Screens Specs, inventory/product baseline.

**Решение:** [принято] (2026-10-18) Единая пользовательская настройка «Учитывать архивные» действует на всю главную и сохраняется между посещениями. Включена по умолчанию: ACTIVE + ARCHIVED; выключена: только ACTIVE; TRASH исключён всегда. Calendar, Statistics (все показатели, включая Drafts/Needs attention), TagCloud и EntryList используют одну область для отображения/подсчёта и переходов в Browser. Прежний Active-only scope Home TagCloud/EntryList заменён этим правилом; периоды, сортировка и лимит 7 Entries сохранены.
