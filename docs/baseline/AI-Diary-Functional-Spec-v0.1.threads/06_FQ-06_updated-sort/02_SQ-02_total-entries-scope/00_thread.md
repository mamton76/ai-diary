## Вопрос

Какие lifecycle-состояния входят во «Всего записей» / Total entries на Home за всё время?

## Варианты

1. **Рекомендация:** ACTIVE + ARCHIVED, без TRASH. Архив остаётся частью дневника; удалённые в корзину записи не входят в общий показатель. Переход открывает тот же scope.
2. Только ACTIVE; архивные доступны в отдельной выборке и не входят в общий показатель.
3. Все состояния, включая TRASH; число должно явно объяснять включение корзины.

## Контекст

- Период Total entries уже определён как «за всё время»; это не определяет lifecycle.
- [SQ-01](../01_SQ-01_home-queue-scope/00_thread.md) задаёт ACTIVE + ARCHIVED, без TRASH для рабочих очередей Drafts / Needs attention. Это не автоматический выбор для Total entries.
- Считаются уникальные Entry, а не Revision; число и список по клику используют один predicate.
- Home EntryList и TagCloud имеют собственный ACTIVE scope; scope остальных статистических counters остаётся отдельным вопросом.
