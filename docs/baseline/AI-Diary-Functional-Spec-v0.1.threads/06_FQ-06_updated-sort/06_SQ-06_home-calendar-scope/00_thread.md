## Вопрос

Должен ли Calendar на Home выделять дни с архивными Entries и включать их в список по выбранному дню/диапазону, или учитывать только ACTIVE? TRASH предлагается исключить в обоих вариантах.

## Варианты

1. **Рекомендация:** ACTIVE + ARCHIVED, без TRASH. Архивация не убирает прошлые события из календарной хронологии. Индикатор и список по клику имеют один и тот же scope.
2. Только ACTIVE; дни и выборка архивных Entries доступны при отдельном явном выборе архива в Browser.

## Контекст

- Calendar показывает наличие Entry в днях без counts/state badges. Выбор любого дня/диапазона открывает Browser; пустой день не создаёт новую Entry.
- Приняты local event dates, period overlap, включение последнего date-only дня и соответствие индикатора результату выборки. Это не выбирает lifecycle автоматически.
- Home counters Total/Drafts/Needs attention/периодная статистика уже включают ACTIVE + ARCHIVED, без TRASH.
- Home EntryList и TagCloud имеют собственный ACTIVE scope; текущий выбор не расширяет их.
- Текущий вопрос относится к Calendar на Home; общий переиспользуемый компонент получает scope от контейнера и не должен навязывать Home policy другим экранам.
- Точное время события, timezone и current Draft-state используют общие принятые правила. Этот выбор не меняет Entry lifecycle и не добавляет badge/state clutter в календарь.

## Обсуждение

Codex — (2026-10-18) Предлагаю Calendar Home учитывать активные и архивные записи, исключая корзину. Тогда архивация не убирает прошлые события из хронологии; выбор дня показывает записи того же состава, по которому он выделен. Это рекомендация, ещё не принятое правило.

пользователь — (2026-10-18) «вроде да (+ дополнительно вомзодно в настроках отключить показ архивных и их учет?)»

Codex — (2026-10-18) Default ACTIVE + ARCHIVED без TRASH согласован; дополнительное предложение — настройка исключения архива. Область настройки не приписываю автоматически всем показателям/очередям Home. Default перенесён в source; [SQ-07](../07_SQ-07_archive-visibility-setting/00_thread.md) отдельно уточняет scope переключателя. Если настройка действует на Calendar, индикатор и список по клику должны переключаться вместе.

**Решение:** [принято] (2026-10-18) Calendar на Home по умолчанию учитывает ACTIVE и ARCHIVED Entries, исключая TRASH. Выделение дней и список по выбранному дню/диапазону используют одинаковый lifecycle scope. Календарь сохраняет местные даты событий и принятую period-overlap semantics; state badges и counts в ячейках не добавляются.
