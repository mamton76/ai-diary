## Вопрос

Source: «canonical file, operational DB, оба слоя?» Поля: workflow/version, prompt/version, provider/model, input references, parameters, output, validation, timing, token/cost, review/apply state.

## Варианты

1. **Файл запуска в Drive — источник истины; в БД — производный индекс** для списков, статусов и подсчёта бюджета, пересобираемый из файлов.
2. Только в операционной БД.
3. Только в Drive, без индекса.

## Контекст

- [AQ-SEC-001](../49_AQ-SEC-001_content-protection/00_thread.md) / PRIV-011: долговременные копии содержимого, включая AI run records и debug-копии, — в Drive пользователя; на сервере только кратковременное, derived индекс и токены. Вариант 2 этому противоречит.
- PRIV-006: run record хранит ссылки на Revision и хеш контекста, а не текст; полный prompt/ответ — только в debug-режиме, без автоудаления.
- OPS-RUN-LOG ([AQ-OPS-001](../36_AQ-OPS-001_run-log/00_thread.md)): журнал всех запусков со ссылками на ревизии и proposal/result.
- [07-file-format](../../07-file-format-v1-draft.md) уже предлагает `runs/<runId>/` в Drive, включая failed и non-mutating запуски.
- Минимальный дайджест (AI-037) — первый потребитель.

## Обсуждение

Claude — Рекомендую **вариант 1**; по сути он уже следует из AQ-SEC-001 и 07, тред нужен, чтобы закрыть вопрос явно.

- `runs/<runId>/run.json` в технической подпапке Drive: workflow/version или system workflow id, модель и провайдер, ссылки на входные Revision и хеш контекста, параметры, статус, ошибка, время, токены и стоимость, ссылки на AIResult/proposal и итоговую Revision.
- Результат AI (например, текст предложенного дайджеста) — отдельный файл AIResult рядом, потому что это содержимое.
- Debug-копии prompt и ответа — `runs/<runId>/debug/`, только при включённом debug, очищаются командой (PRIV-006).
- Операционная БД держит производный индекс: список запусков, статусы, суммарные расходы за месяц для бюджета. Индекс пересобирается из файлов; расход бюджета не теряется при потере БД.
- Хранятся бессрочно: файлы маленькие, а история запусков нужна для разбора и бюджета.
