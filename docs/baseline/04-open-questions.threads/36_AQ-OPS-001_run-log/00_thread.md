## Вопрос

Какие сведения хранить обо всех capture/sync/AI workflow runs, обеспечив диагностику без ненужных копий личных данных?

## Обсуждение

ChatGPT — Варианты: минимальный лог только статусов/ошибок; структурированный журнал со статусом, этапом, моделью, длительностью, попытками и ссылками на вход/выход; полный журнал с дублированием payload/prompts; два уровня: структурированный постоянный журнал и опциональная расширенная диагностика. Рекомендую хранить structured metadata всегда, подробные sensitive payload не копировать по умолчанию. Уточняющий вопрос: фиксировать все запуски или только ошибки?
