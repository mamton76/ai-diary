## Вопрос

Что происходит с дайджестом, который пользователь не принял и не отклонил?

## Варианты

1. Висит, пока пользователь его не откроет.
2. Устаревает.

## Контекст

- Proposal не исчезает из истории (AI-09).

## Обсуждение

Claude — (2026-11-15) Что происходит с непринятым дайджестом: висит, пока вы его не откроете, или устаревает?

пользователь — непринятый - давай устаревает через пару напоминаний (будем настраивать) и какой-то срок (тоед будем настраивать)

Claude — Принято: дайджест устаревает. Оба параметра — настройки пользователя: число напоминаний (по умолчанию 2 — «пару») и срок; значение срока по умолчанию выбирается при реализации и потом настраивается. Техническая конкретизация без нового выбора: напоминания приходят в пределах срока; по его истечении дайджест получает статус «Устарел», Entry не создаётся, proposal остаётся в истории (AI-09). Решение перенесено в source-документы.

**Решение:** [принято] (2026-11-15) Непринятый дайджест устаревает. До этого приходят напоминания: их число настраивается, по умолчанию 2. Срок тоже настраивается; значение по умолчанию выбирается при реализации. Напоминания приходят в пределах срока; по его истечении дайджест получает статус «Устарел», Entry не создаётся, proposal остаётся в истории.
