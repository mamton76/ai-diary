## Вопрос

Как представить три роли Base / Result / Proposal на узком экране телефона?

## Варианты

1. Переключатель «Исходник / Результат / Предложение AI»: одна роль видна за раз, при входе открыт редактируемый Result.
2. Три панели одна под другой в общей прокрутке, без переключения.

## Контекст

- На широком экране уже приняты три панели: Base read-only, Result editable, Proposal read-only; изменения Result и Proposal подсвечены относительно Base.
- Обычный Compare C15 уже имеет mobile Before/After либо inline diff; это не выбор заново для C15.
- S07 прямо оставляет mobile layout трёхстороннего proposal review открытым; sequential Base/Result/Proposal пока помечен предложением.
- UI-Q06 существует в source; отдельный canonical thread в текущем index/sibling-каталоге не найден.
- Переключение представления не создаёт Revision и не теряет общий review draft; существующие autosave/resume/dirty/freshness guards сохраняются.
- Условия Apply, Current conflict choice и статус «Принято частично» не меняются.

## Обсуждение

Codex — (2026-10-18) После validation Save следующий незакрытый пункт — UI-Q06. Рекомендую на телефоне один переключаемый раздел «Исходник / Результат / Предложение AI», с открытым Result при входе. Изменения Result и Proposal подсвечиваются относительно Base, редактируется только Result; выбор вкладки сохраняет правки. Apply доступен из Result. Альтернатива — три длинные панели в общей вертикальной прокрутке. Это предложение, не принятое требование.

пользователь — (2026-10-19) «ну ок.. может в ландшавте все же 2?»

Codex — (2026-10-19) Предложены две панели в landscape: редактируемый Result и переключаемый read-only Base/Proposal. В исходном предложении portrait ещё использовал одну роль за раз; пользователь сразу уточнил его следующим ходом.

пользователь — (2026-10-19) «да и в портрете наверное друг надо другом можено?»

Codex — (2026-10-19) Принято направление двух областей в обеих ориентациях: Result + Base/Proposal; landscape рядом по доступной ширине, portrait одна над другой. Конкретная расстановка, пропорции и breakpoint — реализация, не отдельный запрос подтверждения. Смена ориентации/переключателя не теряет общий review draft; роли редактирования, подсветка относительно Base, Current conflict choice и Apply сохраняются. Исходный вариант единственной панели с тремя вкладками не выбран как основной mobile layout. Решение перенесено в обе спецификации и inventory/product baseline.

**Решение (уточнено следующим ходом, 2026-10-19):** [принято] (2026-10-19) На телефоне подробный AI review имеет две области: редактируемый Result и read-only панель со сменой Base/Proposal. В landscape они рядом при достаточной ширине, в portrait — одна над другой. Три смысловые роли, diff относительно Base и общий review draft сохраняются при повороте/переключении, Apply подтверждает Result; desktop по-прежнему использует три панели.

пользователь — (2026-10-19) «давай в настройки это вынессем - где у нас там настройки экранов и попробуем и так и так?»

Codex — (2026-10-19) Итог уточнён: оба mobile-варианта доступны как пользовательская настройка экрана AI review. В S11 добавлена группа «Отображение» с настройкой «Проверка AI»: «Переключение» и «Две панели». Две панели остаются начальным вариантом по предыдущему ходу; выбор сохраняется, чтобы можно было попробовать оба. Режимы используют один review draft, поворот/смена режима не теряет правки и не выполняет Apply. Сохранена история предыдущего направления; source обновлён итоговым контрактом.

**Решение:** [принято] (2026-10-19) Mobile AI review имеет сохраняемую пользовательскую настройку S11 «Отображение → Проверка AI»: «Переключение» (Base/Result/Proposal по одной роли, начально Result) либо «Две панели» (Result + read-only Base/Proposal, landscape рядом по ширине, portrait друг над другом). Изначально две панели, оба варианта можно попробовать. Меняется только отображение: общий review draft/правки/диффы и прежние guards сохраняются; Apply не происходит от смены режима. Desktop сохраняет три панели.
