## Вопрос

Что видит пользователь, если при ручном Save оказывается, что текущая версия записи изменилась после того, как он начал правку? Screens Spec говорит только «UI показывает conflict/rebase flow, не last-write-wins», а экрана для этого нет.

## Варианты

1. **Автоматическое объединение по полям плюс экран сравнения.** Если изменились разные поля (например, кто-то поменял теги, а пользователь — текст), правки объединяются автоматически с заметным уведомлением. Если изменено одно и то же поле — экран «Было / Сейчас / Мой черновик» на основе экрана проверки AI (S07).
2. **Всегда экран сравнения,** без автоматического объединения.
3. **Минимум для первой версии:** Save блокируется, черновик сохраняется, сообщение «Запись изменилась — откройте заново»; полноценный экран позже.

## Контекст

- Источник: [ревью требований 2026-11-08](../../../audits/2026-11-08-requirements-review.md), находка C6.
- Защита от одновременной правки уже есть: один владелец правки на Entry, явный takeover между вкладками и устройствами (AC-08, DATA-014/018). Поэтому параллельная ручная правка с двух устройств сериализуется и сама по себе конфликта не даёт.
- Конфликт возникает, когда текущая версия ушла вперёд от базы черновика другим путём: внешнее изменение файла в Drive (DATA-011, AQ-DATA-004), применённое AI-изменение, Restore на другом устройстве после takeover. Случай редкий, но в первой версии возможен.
- Экран S07 уже показывает три роли Base / Result / Proposal и умеет «оставить текущее / взять предложение / поправить вручную».
- REV-011/FQ-01: любая новая версия не удаляет предыдущие, всё остаётся в истории.

## Обсуждение

Claude — Рекомендую **вариант 1**.
- Разные поля объединяются без вопросов: это не потеря данных, а уведомление «Объединено с изменениями от … » показывает, что произошло.
- Для одного и того же поля — экран сравнения, переиспользующий S07: «Было» (база черновика), «Сейчас» (текущая версия), «Мой черновик» (редактируемый результат). Действия: «Сохранить мою версию», «Оставить текущую», «Поправить вручную».
- «Сохранить мою версию» не является тихой перезаписью: текущая версия остаётся в истории, а пользователь сделал выбор осознанно.
- Вариант 3 дешевле, но с ним пользователь вынужден вручную переносить свой текст. Поскольку S07 всё равно строится к E4, а первая версия правит только заголовок и текст, на первой версии можно сделать упрощённый экран для этих двух полей.

**Решение:** [принято] (2026-11-08) Если при ручном Save текущая версия ушла вперёд от базы черновика: изменения в разных полях объединяются автоматически с заметным уведомлением «Объединено с изменениями от …»; если изменено одно и то же поле, открывается экран сравнения «Было / Сейчас / Мой черновик» на основе S07 с действиями «Сохранить мою версию», «Оставить текущую», «Поправить вручную». «Сохранить мою версию» создаёт новую Revision, текущая остаётся в истории. В первой пользовательской версии экран упрощён до заголовка и текста; полный вариант — с полным редактором (E2).
