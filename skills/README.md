# AI Diary — проектные навыки агентов

Эта папка содержит **канонические проектные skills**, общие для ChatGPT/Codex, Claude Code и других агентов, работающих с репозиторием.

## Зачем отдельные project skills

В AI Diary есть рабочие соглашения, которые не являются ни продуктовыми требованиями, ни архитектурой:

- как вести длинные обсуждения;
- как фиксировать открытые вопросы;
- как принимать и пересматривать решения;
- как проводить review;
- как обновлять source-документы после решения;
- как передавать работу между разными агентами без потери контекста.

Такие правила должны жить в репозитории и эволюционировать вместе с проектом, а не оставаться только в истории чатов или в локальной конфигурации одного агента.

## Канонический источник

Каждый навык хранится в:

```text
skills/<skill-name>/SKILL.md
```

Это **единственная каноническая версия** правил навыка.

Адаптеры конкретных агентов могут лежать в их служебных каталогах, но не должны содержать независимую копию правил. Они только указывают на канонический skill.

Пример для Claude Code:

```text
.claude/skills/discussion-threads/SKILL.md
    -> skills/discussion-threads/SKILL.md
```

Для ChatGPT/Codex общие проектные правила перечислены в корневом `AGENTS.md`.

## Текущие skills

### discussion-threads

`skills/discussion-threads/SKILL.md`

Используется для длинных проектных вопросов и решений: один вопрос — один тред, явный ход пользователя, история пересмотренных решений, вложенные подтреды и обязательное обновление исходного документа после принятия решения.

## Правила развития skills

1. Сначала меняется канонический `skills/<name>/SKILL.md`.
2. Адаптеры конкретных агентов меняются только если изменился способ обнаружения/запуска навыка.
3. Правила не должны silently расходиться между ChatGPT и Claude.
4. Если skill меняет формат уже существующих тредов, миграция обсуждается отдельно; старые треды не переписываются молча.
5. Skills можно версионировать в frontmatter, если появятся автоматические скрипты/линтеры, завязанные на формат.
